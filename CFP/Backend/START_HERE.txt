═══════════════════════════════════
STEP 1: COPY THIS FOLDER
═══════════════════════════════════

Use this project from:
C:\kvt gym\CFP\

The active backend is inside:
C:\kvt gym\CFP\Backend\

═══════════════════════════════════
STEP 2: START MONGODB
═══════════════════════════════════

1. Press Windows + R
2. Type: services.msc → Press Enter
3. Find "MongoDB Server" in the list
4. Right click → Start

If MongoDB is not installed:
→ Download from: mongodb.com/try/download/community
→ Install and restart

═══════════════════════════════════
STEP 3: INSTALL PACKAGES
═══════════════════════════════════

Open PowerShell and run:

  cd "C:\kvt gym\CFP\Backend"
  npm install

Wait for it to finish (2-3 minutes first time)

═══════════════════════════════════
STEP 4: START BACKEND
═══════════════════════════════════

  npm run dev

You should see:
  ✅ MongoDB Connected
  🚀 http://localhost:5000/api

═══════════════════════════════════
STEP 5: TEST IT WORKS
═══════════════════════════════════

Open browser and go to:
  http://localhost:5000/api/health

Should show: "💪 Classic Fitness Park API is Running!"

═══════════════════════════════════
STEP 6: CREATE ADMIN ACCOUNT
═══════════════════════════════════

In a NEW PowerShell window:

  cd "C:\kvt gym\CFP\Backend"
  copy .env.example .env
  notepad .env
  npm run seed

Set these in `.env` before seeding:
  SEED_ADMIN_PASSWORD=...
  SEED_TRAINER_PASSWORD=...
  SEED_MEMBER_PASSWORD=...

This creates:
  Admin:   admin@classicfitnesspark.com.np
  Trainer: rajesh@cfp.com
  Member:  ram@example.com

═══════════════════════════════════
STEP 7: OPEN FRONTEND
═══════════════════════════════════

In another PowerShell:

  cd "C:\kakarvitta gym\CFP\frontend"
  python -m http.server 8080

Open browser: http://localhost:8080

═══════════════════════════════════
IF STILL NOT WORKING
═══════════════════════════════════

Problem: Port 5000 already in use
Fix: Run this in PowerShell as Administrator:
  netstat -ano | findstr :5000
  taskkill /PID <NUMBER_SHOWN> /F
  npm run dev

Problem: MongoDB won't start
Fix: Open PowerShell as Administrator:
  net start MongoDB

Problem: npm not found
Fix: Install Node.js from nodejs.org

GET  /api/products         → All products
POST /api/manual-payments/submit → Submit QR payment
GET  /api/dashboard/admin  → Admin stats
GET  /api/health           → Health check
